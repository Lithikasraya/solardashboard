# 3 kW Solar Panel Monitoring Dashboard

React + Vite + Tailwind simulation of a solar panel monitoring UI.

Features:
- Real-time simulated Voltage, Current, Power, Temperature
- Animated metric cards with glassmorphism
- Line and bar charts (Recharts)
- Power utilization gauge and system health panel

Quick start:

1. Install dependencies:

```bash
npm install
```

2. Run dev server:

```bash
npm run dev
```

Open the URL printed by Vite (usually http://localhost:5173).

Notes:
- Tailwind is configured with `dark` class mode; use the toggle in the header.
- Exports and toasts are placeholders you can wire to real implementations.
