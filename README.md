# 3 kW Solar Panel Monitoring Dashboard 🌞

## College Project: Advanced Smart Solar Energy Monitoring System

A professional, responsive React + Vite + Tailwind CSS web dashboard that simulates real-time monitoring of a 3 kW solar panel system. Perfect for final-year projects, smart energy demos, and solar monitoring system simulations.

---

## 📋 Project Overview

This dashboard displays real-time electrical and environmental parameters of a solar panel installation with an interactive map-based visualization. It educates users about power generation, financial benefits, and energy distribution.

---

## 🎯 Dashboard Features & Components

### **1. Header Section**
- **Title & Subtitle**: "3 kW Solar Panel Monitoring Dashboard" with real-time energy performance subtitle
- **Dark/Light Mode Toggle**: Button to switch between dark and light themes
- **Solar Icon**: Visual indicator of the solar system

### **2. Real-Time Metric Cards (Top Row)**
Four animated glassmorphic cards displaying live system parameters:

#### **Voltage Card ⚡**
- Current voltage reading: 250–450 V
- Color-coded indicator (Green ✓ / Yellow ⚠ / Red ✗)
- Real-time updates every 1.5 seconds
- Circular progress indicator showing % utilization

#### **Current Card 🔋**
- Current flow: 0–12 A
- Threshold-based color coding
- Animated updates with smooth transitions
- Shows system load percentage

#### **Power Output Card ⚡**
- Real-time power: 0–3.0 kW
- Capacity utilization gauge (0–100%)
- Color-changing bar (green → yellow → red)
- Displays both current and max capacity

#### **Panel Temperature Card 🌡️**
- Temperature range: 25–75 °C
- Alert thresholds for overheating
- Color indicators for thermal status
- Helps monitor panel health

### **3. Interactive Map Panel**
- **Location Pin**: Shows solar installation location (Delhi coordinates by default)
- **Power Flow Visualization**: 
  - Green line → Local usage area
  - Blue line → Grid interconnection point
- **Animated Markers**: 
  - Solar system source
  - Local consumption area
  - Grid connection point
- **Hover Tooltips**: Location info, installed capacity, energy supplied
- **OpenStreetMap Integration**: Realistic geographical visualization

### **4. Power & Energy Insights Panel**
Tracks energy production over time:

#### **Metrics Displayed**
- **Today's Power Generation**: Current kW output
- **Daily Energy**: Cumulative kWh generated today
- **Monthly Energy**: Total kWh for the month
- **Yearly Energy**: Annual production total
- **Lifetime Energy**: Total energy ever generated by system

#### **Capacity Usage Bar**
- Visual progress bar showing system utilization
- Color-coded (Green = optimal, Yellow = medium, Red = low)
- Percentage display for quick understanding

### **5. Revenue & Cost Savings Module 💰**
Shows financial benefits of the solar system:

#### **Metrics**
- **Money Earned Today**: Currency-based daily earnings
- **Monthly Revenue**: Estimated monthly income from grid export
- **Lifetime Earnings**: Total revenue accumulated
- **ROI / Payback Period**: Years to recover system cost (estimated)
- **Grid Feed-in Tariff**: Configurable rate (₹/kWh or $/kWh)

#### **Features**
- Currency toggle (₹ Indian Rupee or $ USD)
- Tariff rate adjustment
- Real-time earnings calculation based on exported power

### **6. Power Distribution Panel**
Visual breakdown of where generated power goes:

#### **Distribution Breakdown**
- **Owner Use**: % of power used locally
- **Grid Export**: % of power sold to grid
- **Battery Storage**: % charging/storing (if available)

#### **Visualization**
- Circular gauge showing primary usage percentage
- Real-time updates as generation varies
- Color-coded sections for easy interpretation

### **7. Charts & Analytics Section**

#### **Power vs Time (Line Chart)**
- Time-series visualization of power output
- Last 60 seconds of data
- Shows generation trends
- X-axis: Time, Y-axis: Power (kW)

#### **Voltage & Current (Bar Chart)**
- Side-by-side comparison of V and A
- Real-time updates
- Helps identify electrical imbalances
- Threshold indicators

#### **Power Utilization Gauge (Circular)**
- Donut/circular progress indicator
- Shows % of 3 kW capacity in use
- Smooth animations
- Color gradient based on load

### **8. System Health Panel**
Real-time system status overview:

#### **Status Badge**
- **Normal** (Green): All parameters optimal
- **Overload** (Yellow): Power or temp near limits
- **Offline** (Gray): System not producing

#### **Efficiency Percentage**
- Calculates (Current Power / Max Capacity) × 100
- Visual progress bar
- Helps identify underperformance

#### **Warnings & Alerts**
- High panel temperature warning
- Power near maximum capacity alert
- Grid outage notifications
- Maintenance reminders

#### **Summary Stats**
- Current voltage, current, power, temperature
- Quick reference values

### **9. Smart Recommendations Panel 🧠**
AI-like suggestions for optimizing energy use:

Examples:
- "High generation detected – run heavy appliances now"
- "Low solar output due to weather"
- "Battery charging recommended"
- "You earned ₹XXX today from grid export"
- "System operating normally – no immediate actions"

### **10. Alerts & Notifications Panel 🔔**
Real-time alert system:

#### **Alert Types**
- ⚠️ **Warning**: High temperature, low generation
- 🔴 **Danger**: System offline, critical faults
- ℹ️ **Info**: Normal operation, routine updates

#### **Notification Bell**
- Visual indicator of active alerts
- Color-coded severity levels
- Dismissible notifications

### **11. Settings & Customization Panel ⚙️**
User controls for personalizing the dashboard:

#### **Available Settings**
- **Currency Selection**: Switch between ₹ and $
- **Tariff Rate**: Set your grid feed-in rate (e.g., 6.5 ₹/kWh)
- **Grid Export Toggle**: Enable/disable power export to grid
- **Location Configuration**: Update installation location

#### **Persistent Preferences**
- Settings applied immediately to all calculations
- Revenue displays update in real-time
- Recommendations adjust based on export status

## 🚀 Quick Start Guide

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation

1. **Clone or navigate to project folder:**
```bash
cd "C:\Users\lithi\OneDrive\Desktop\solar demo"
```

2. **Install dependencies:**
```bash
npm install
```

3. **Start development server:**
```bash
npm run dev
```

4. **Open in browser:**
```
http://localhost:5173/
```

### Build for Production

```bash
npm run build
```

Output will be in `dist/` folder, ready for deployment.

## 📊 Data Simulation

All real-time data is simulated using:
- **Random generators** for realistic variance
- **useEffect + setInterval** for 1.5-second updates
- **useState** for state management
- **Accumulation logic** for energy totals

### Simulated Parameters
| Parameter | Range | Type |
|-----------|-------|------|
| Voltage | 250–450 V | Analog |
| Current | 0–12 A | Analog |
| Power | 0–3.0 kW | Derived |
| Temperature | 25–75 °C | Analog |

## 🔧 Customization

### Change System Capacity
Edit `Dashboard.jsx`:
```javascript
<MetricCard title="Power" value={metrics.power} unit="kW" max={5} />
```
(Change `max={3}` to desired capacity)

### Adjust Simulation Speed
Edit `Dashboard.jsx`:
```javascript
}, 1500)  // Change 1500 (milliseconds) to faster/slower
```

### Modify Color Thresholds
Edit `MetricCard.jsx`:
```javascript
const thresholds = [300, 400]  // Green if 300–400V, yellow below, red above
```
